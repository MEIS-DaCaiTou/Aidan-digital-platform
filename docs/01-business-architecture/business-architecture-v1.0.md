# 服装集团数字化业务架构蓝图 V1.0

> 文档级别：集团数字化规划顶层基线（可用于软件选型、系统招标、产品原型与后续开发拆解）
> 冻结日期：2026-09
> 状态：V1.0 已冻结

## 一、总体设计目标

假设集团业务形态：多品牌 + 多法人 + 多渠道 + 多仓库 + 多供应商 + 自有/外协生产 + 直营门店 + 加盟/经销 + 电商平台 + 私域商城。

集团系统要解决六个核心问题：

1. 商品是什么？
2. 应该生产/采购多少？
3. 货在哪里？
4. 应该卖到哪里？
5. 卖给了谁、赚了多少钱？
6. 下一步应该生产、补货、调拨还是清仓？

核心链路：

```
商品企划 → 设计研发 → 采购/生产/供应 → 仓储物流 → 商品运营
                                                     │
                         ┌───────────┬───────────┬───┘
                         ▼           ▼           ▼
                      直营门店      电商平台    加盟/批发
                       POS          OMS         DMS/B2B
                         └───────────┴───────────┘
                                     ▼
                              统一订单中心 OMS
                                     ▼
                              统一库存中心 IMS
                                     ▼
                              会员/客户中心
                                     ▼
                              财务结算中心
                                     ▼
                              数据平台 / BI
                                     ▼
                                AI 经营决策
```

## 二、集团业务架构（10 大业务域）

1. **集团战略与经营管理**：战略目标、年度预算、品牌经营、事业部经营、经营分析
2. **商品全生命周期**：商品企划 → 设计研发 → 打版 → 样衣 → 核价 → 大货确认；季节/波段/品类、款式/颜色/尺码、BOM/面料/辅料、工艺/尺寸/成本
3. **供应链业务**：供应商 → 询价 → 采购 → 生产计划 → 生产 → 质检 → 入库（SRM / SCM / ERP / APS / MES / QMS / WMS）
4. **商品运营**：首铺 → 配货 → 补货 → 调拨 → 促销 → 降价 → 清仓；销售预测、售罄分析、库存结构、尺码结构、区域分析
5. **全渠道销售**：门店 POS、电商（抖音/天猫/京东/拼多多）、私域（小程序/企微/APP）、加盟 DMS、批发 B2B
6. **客户经营**：会员 → 标签 → 等级 → 积分 → 优惠券 → 私域 → 自动营销（CRM / CDP / Marketing Automation）
7. **财务经营**：收入 → 成本 → 应收 → 应付 → 对账 → 结算 → 总账 → 税务（财务共享 / ERP / FMS）
8. **数据与决策**：数据仓库 → 指标中心 → BI → 预测 → AI 决策（销售/库存/毛利/商品/门店/渠道/供应链/客户）
9. **组织与人力**：HR / OA / BPM
10. **数字基础**：MDM / 集成平台 / 技术平台

**原则：业务应用层不是中台。** ERP、WMS、PLM、MES 都是专业业务系统；集团中台解决多品牌、多渠道、多系统之间必须共享的一致能力。

## 四、集团最重要的八大中心

| 中心 | 核心职责 |
|---|---|
| 商品中心 | SPU、SKU、款号、颜色、尺码、品牌、类目、属性 |
| 库存中心 IMS | 实物库存、可售库存、锁定库存、在途、预占 |
| 订单中心 OMS | 全渠道订单、拆单、合单、路由、履约 |
| 价格中心 | 吊牌价、零售价、会员价、渠道价、地区价 |
| 促销中心 | 满减、折扣、优惠券、组合促销 |
| 客户/会员中心 | One ID、积分、等级、标签、权益 |
| 结算中心 | 平台、门店、加盟商、供应商、物流结算 |
| 供应商中心 | 供应商主档、能力、合同、产能、评分 |

其中最重要的三个：**商品中心 → 库存中心 → 订单中心**。

## 五、商品主数据模型

```
集团 → 品牌 → 年份 → 季节 → 波段 → 产品线 → 品类 → 款式 SPU → 颜色 → 尺码 → SKU
```

示例：品牌 A / 2027 春夏 / 春一波 / 女装外套 / 款号 A27JK001 / 短款轻薄夹克 / 颜色 01黑 02米白 03卡其 / 尺码 S M L XL → 3×4 = 12 个 SKU。

所有系统必须统一一套商品模型，不能 PLM 一套编码、ERP 一套、WMS 一套、电商再一套。

## 七、商品生命周期数据流

```
年度经营目标 → 品牌商品战略 → 商品企划 → 品类规划 → 价格带规划 → 波段规划 → 款式规划
→ PLM 款式立项 → 设计稿 → 颜色/尺码 → 面料/辅料 → BOM → 工艺 → 打版 → 样衣
→ 样衣评审 → 成本核算 → 订货评审 → 正式款号 → SPU/SKU 创建 → 商品中心
→ ERP（采购/生产）与 WMS、OMS（渠道销售）
```

## 八、供应链数据流

```
销售目标 → 商品企划 → 需求预测 → 采购/生产需求 → APS 计划 → MRP → 采购计划
→ 供应商询价 → SRM → 采购订单 → 生产订单 → 供应商/工厂 → 原料 → 裁剪 → 车缝
→ 后整 → 质检 → 包装 → 成品入库 → WMS
```

回流：生产进度 → MES → ERP/SCM → 商品运营；交期异常 → 预警中心；质量异常 → QMS → 供应商评分。

## 九、库存三层概念与 ATP

- 第一层：实物库存（WMS）
- 第二层：库存中心 IMS
- 第三层：渠道库存

```
ATP = 实物库存 - 残次品 - 质检锁定 - 订单预占 - 安全库存 - 其他渠道占用
```

示例：上海仓实物 1000 − 质检冻结 50 − 订单锁定 200 − 安全库存 100 − 门店预留 150 = 可售 500，再分配抖音 150 / 天猫 150 / 京东 50 / 微信 50 / 其他 100。

## 十、全渠道订单数据流

```
消费者 → 抖音 → 订单接口 → OMS → 订单校验 → IMS → 锁库存 → 智能履约
（订单地址 + 仓库库存 + 门店库存 + 物流成本 + 预计送达 + 仓库负载 → 中央仓或门店发货）
→ WMS → 波次 → 拣货 → 复核 → 打包 → 电子面单 → TMS → 快递 → 消费者
→ 物流签收 → OMS → 平台 → 财务结算
```

## 十一、退换货数据流

```
消费者申请退货 → 平台/门店 → OMS 售后 → RMA 退货单 → 物流 → 仓库 → WMS 收货 → 质检
→ 可再次销售（恢复 ATP）/ 次品（残次库存）/ 报废
→ OMS → 退款 → 平台 → 财务
```

## 十二、商品运营数据流

持续判断：销售、库存、售罄、折扣、毛利、天气、区域、门店等级、尺码结构 → 产生补货建议、调拨建议、返单建议、降价建议、促销建议、清仓建议。

典型：上海 A 店 M 码销量 50 库存 2；广州 B 店 M 码销量 5 库存 40 → 系统建议广州→上海调拨 25 件。**该部分适合成为企业自己的核心商品运营平台。**

## 十三、会员数据流

POS / 抖音 / 天猫 / 微信 / 官网 / APP / 客服 → 客户中心 → One ID → CDP（基础属性、交易属性、商品偏好、品牌偏好、颜色偏好、尺码偏好、价格带、折扣敏感度、渠道偏好、复购周期、生命周期）→ 人群包 → 营销自动化 → 短信/微信/企微/APP/广告。

## 十四、财务数据流

```
POS / 电商 / 经销 → OMS/DMS → 对账中心 → 结算中心 → 应收/应付/费用 → ERP → 总账 → 利润/现金流
成本 = 原料 + 加工 + 包装 + 物流 + 平台佣金 + 渠道费用 + 门店费用 = 真实商品成本 → 商品真实贡献毛利
```

## 十五、数据平台数据流

```
业务系统（PLM/ERP/SRM/MES/QMS/WMS/TMS/OMS/IMS/POS/CRM/CDP/DMS/电商）
→ CDC/API/MQ → ODS → Data Lake/Warehouse → DWD → DWS → 指标中心 → BI → AI
→ 集团 → 品牌 → 渠道 → 大区 → 城市 → 门店 → 商品 → 颜色 → 尺码
```

## 十八、买 vs 自研建议

- **采购成熟产品**：ERP、财务系统、WMS、TMS、HR、OA、APS、QMS、CDP（平台产品+自有数据模型）、POS（成熟产品+集团接口标准）
- **采购 + 深度定制**：PLM、SRM、MES、CRM、DMS/B2B（视加盟业务差异）
- **自研/深度定制**：商品企划、商品运营、配货补货、商品中心、库存中心 IMS、价格中心、促销中心、会员中心（One ID）、集成平台、MDM、BI、AI 平台、电商商品发布中心
- **成熟核心 + 自研编排**：订单中台 OMS

## 十九、真正值得自研的核心

集团数字业务平台：商品中心、商品企划平台、商品运营平台、PIM、DAM 素材中心、渠道商品发布中心、OMS 编排层、IMS 库存中心、价格中心、促销中心、配货中心、补货中心、调拨中心、会员中心、数据指标中心、AI 智能运营平台。

## 二十、最终集团系统关系

```
集团经营平台（BI/AI） → 数据平台（DWH/Lake/指标） → 集团数字业务中台（商品/库存/订单/价格/促销/客户/结算/供应商）
→ 商品供应链（PLM/SRM/APS/MES/QMS/WMS/TMS） | 全渠道销售（OMS/IMS/POS/电商/DMS/CRM/CDP） | 企业经营（ERP/财务/HR/OA）
→ API / Event Bus → MDM
```

## 二十一、核心闭环

```
商品 → 供应链 → 库存 → 渠道 → 订单 → 客户 → 资金 → 数据 → 决策 → 重新指导商品
```

以后无论增加抖音、小红书、新品牌、新仓库、新门店甚至海外渠道，集团架构都不应推倒重来。
