## 治理规则（已冻结）

1. **一个业务事实，只允许一个系统拥有最终写入权。**
2. 允许：多个系统保存副本、建立搜索索引、数据仓库保存分析快照、下游维护自身执行属性。
3. 不允许：同一 SKU 多个系统都能创建；同一 ATP 多套算法各算一份。
4. AS-IS：仅用于现状调查、迁移分析、历史留档、差异核对。
5. TO-BE V1.0：所有正式 PRD、数据模型、API、事件、权限、研发和验收的唯一基准。
6. 若 AS-IS 与 TO-BE 冲突，默认按迁移问题处理，不反向污染目标架构；只有确认 TO-BE 本身不符合真实业务事实时，才允许走版本变更。
7. **系统可以复制数据，但不能复制数据所有权。**

## 四条冻结原则

- **Product Master 决定**：这个商品是谁。
- **领猫决定**：这个商品是怎么研发、采购和生产出来的。
- **聚水潭/WMS 决定**：货在物理世界里发生了什么。
- **OMS + IMS + Merchandising 决定**：集团如何卖这件商品，以及下一件货应该去哪里。
